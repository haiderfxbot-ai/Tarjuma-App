Privacy Policy

1. Zero Data Collection Architecture

Tarjuman Platform operates under a strict serverless client-side operational infrastructure. We do not provision remote databanks, track sessions, or transmit compiled phonetic string outputs to localized or foreign external server frameworks. All character mapping computations execute explicitly inside your runtime sandbox context.

2. Client-Side Memory Configurations

User preferences including dark amoled states, typography dimension variables, and specific runtime configuration switches are stored locally inside the viewport browser structure utilizing HTML5 LocalStorage APIs. This storage layer remains entirely isolated under the exclusive sandbox limits of your current endpoint.

3. Hardware Integrations & APIs

Phonetic translation modules utilize native Web Speech Recognition and Text-To-Speech Synthesis capabilities embedded in your viewport layer. Audio parameters or text-stream tokens extracted during typing event loops are used exclusively for immediate localized translation processing and are never stored or logged.

4. External Vector Redirections

The Support module contains hyperlinked navigation markers routing to external networks (such as WhatsApp, Telegram, GitHub, and TikTok). Once you exit the application environment via these gateways, your security compliance falls under the terms of service and dynamic operational criteria of those respective vendor configurations.

5. Policy Updates

The platform core architect reserves the right to modify or adjust this privacy layout blueprint to match mandatory system modifications or security compliance upgrades. Your continuous initialization of the application environment translates into automatic validation of these privacy terms.
